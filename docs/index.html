How it works

  • Dozing off — measures how open your eye is relative to the width of your face. Below the threshold for about a second triggers the alarm.
  • Face covered — if no face is visible for about a second and a half, it assumes you have hidden from the camera.
  • Phone — an object detector looks for a phone in frame and calls it out.

The eye threshold is personal: it depends on your face and how far you sit from the camera. Watch the number on screen with your eyes open and again with them closed, then set the slider between the two.

Runs offline in your browser using MediaPipe. Camera access requires an https:// address.
